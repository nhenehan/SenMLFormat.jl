Errors

SenMLFormat.SenMLError — Type
SenMLError <: Exception

Everything that can go wrong reading, checking, resolving or writing SenML. kind names what went wrong; the names are those of rsenml's Error variants:

kindMeaning
:Syntaxthe input is not well-formed JSON, CBOR, XML or EXI (format, offset, reason)
:Incompletethe input ended inside the pack (format); for a SenSML stream: wait for more bytes
:WrongTypea registered label has a value of the wrong type (record, label)
:DuplicateLabela label occurs twice in one record (record, label)
:MultipleValuesmore than one of v, vs, vb, vd (record)
:MustUnderstandan unknown label ending in _ (record, label)
:InvalidLabelan extension uses the name of a registered label (record, label)
:InvalidBase64vd is not unpadded base64url (record)
:NonFinitea number is infinite or NaN (record, label)
:EmptyPacka pack needs at least one record
:MissingValuea record with regular fields but neither a value nor a sum (record)
:MissingNamea measurement with no name and no base name (record)
:InvalidNamebase name + name breaks the rule of RFC 8428 section 4.5.1 (record)
:InvalidVersionbver is not a positive integer (record)
:UnsupportedVersionbver is newer than 10 (record, version)
:InconsistentVersionrecords with different versions (record)
:UnregisteredUnita unit outside the registry, when registered units are required (record)
:RelativeTimea relative time and no "now" to resolve it (record)
:Structurethe XML or EXI root or record element is wrong (format, reason)
:SchemaIdthe EXI stream does not name schemaId "a" (found)
:Unrepresentablethe value cannot be written in this representation (format, reason)
:Exian EXI error with no SenML meaning (reason)

record is the 1-based position of the record in the pack (0 when it does not apply). offset is a 0-based byte offset into the input (-1 when it does not apply); EXI works in bits, so it gives the byte that holds the bit. format is :json, :cbor, :xml, :exi, or :none.
