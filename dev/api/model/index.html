Records and packs

The data model every format shares. A Pack is a vector of Records, each as written, base fields included.

SenMLFormat — Module
SenMLFormat

Sensor Measurement Lists (RFC 8428): records and packs, read and written as JSON, CBOR, XML and EXI. The Julia twin of the Rust library rsenml: same rules, same bytes.

  • Record, Pack, Extension: records as written, base fields included.
  • validate / Validator: the rules of section 4.
  • resolve / Resolver: records with the base fields applied (section 4.6).
  • lookup_unit, UNITS: the units registry (section 12.1).
  • RecordSelector: rec= fragment identifiers (section 9).
  • MediaType: media types and CoAP Content-Formats (sections 12.3, 12.5).
  • SenMLFormat.decode, SenMLFormat.encode, SenMLFormat.encode_unchecked: any format, chosen by media type. Not exported, as decode and encode are common names; call them as SenMLFormat.decode(SENML_JSON, bytes).
  • SenMLFormat.Json, SenMLFormat.Cbor, SenMLFormat.Xml, SenMLFormat.Exi: the JSON (section 5), CBOR (section 6), XML (section 7) and EXI (section 8) formats, with their record readers, stream writers and options.

SenMLFormat.Record — Type
Record(; bn, bt, bu, bv, bs, bver, n, u, v, vs, vb, vd, s, t, ut, extensions)

One SenML record as written, base fields included. Every field is optional (nothing when absent). Give at most one of v, vs, vb, vd (or value). extensions is a vector of Extensions or label => value pairs.

Record(bn = "urn:dev:mac:0024befffe804ff1:", n = "supply-air", u = "Cel", v = 12.8)

Fields: bn, bt, bu, bv, bs, bver, n, u, value, s, t, ut, extensions. Numbers are Float64, bver is UInt64, value is a Value.

SenMLFormat.Pack — Type
Pack(records)
Pack()

A SenML pack (or a complete SenSML stream): the records in order. A Pack is an AbstractVector{Record}.

source
SenMLFormat.Value — Type
Value

The value of a record (one of v, vs, vb, vd, RFC 8428 section 4.2): Float64 for v, String for vs, Bool for vb, Vector{UInt8} for vd.

source
SenMLFormat.Extension — Type
Extension(label, value)

A field with a label RFC 8428 does not register (section 4.4).

Readers must ignore unknown labels. SenMLFormat still keeps the ones whose value is a single scalar (number, string, Bool or bytes), which is what the CDDL of section 11 allows, so a pack converted from one format to another keeps them. JSON and XML cannot tell a string from base64 data, so an unknown label read from them is never bytes (and from XML always a string).

SenMLFormat.is_base_only — Function
is_base_only(r::Record)

A record with only base fields sets values for the records after it. It is not a measurement itself (see the first record of the example in section 5.1.7).

source
SenMLFormat.has_base_fields — Function

True when the record carries any base field (registered or extension).

source
SenMLFormat.has_regular_fields — Function
has_regular_fields(r::Record)

True when the record carries any regular (non-base) field of RFC 8428. Extensions do not count: a reader ignores labels it does not know (section 4.4), so a record of base fields plus an unknown label is still base-only.
