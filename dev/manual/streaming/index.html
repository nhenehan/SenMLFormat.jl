Streaming with SenSML

In this chapter you'll write records one at a time and read them back as their bytes arrive.

A tank level sensor sends a reading every minute over a connection that stays open. The writer doesn't know how many records there will be, and the reader wants each one as soon as it comes:

# The sensor writes one record each minute into the same stream.
wire = IOBuffer()
encoder = SenMLFormat.Json.StreamEncoder()
SenMLFormat.Json.record!(encoder, wire,
    Record(bn = "urn:dev:mac:0024befffe804ff4:tank:", bt = 1_700_000_000,
           n = "level", u = "m", v = 1.82))
for (minute, level) in ((1, 1.81), (2, 1.79))
    SenMLFormat.Json.record!(encoder, wire, Record(n = "level", t = minute * 60, v = level))
end
SenMLFormat.Json.finish!(encoder, wire)
bytes = take!(wire)
println(String(copy(bytes)))

# The reader gets the bytes in pieces of 16, as a network might deliver them.
decoder = SenMLFormat.Json.StreamDecoder()
for piece in Iterators.partition(bytes, 16)
    push!(decoder, collect(piece))
    while (record = SenMLFormat.Json.next_record!(decoder)) !== nothing
        println("got ", record.n, " = ", repr(record.value))
    end
end
SenMLFormat.Json.finish(decoder)
println("stream finished: ", SenMLFormat.Json.isfinished(decoder))
[{"bn":"urn:dev:mac:0024befffe804ff4:tank:","bt":1700000000,"n":"level","u":"m","v":1.82},{"n":"level","t":60,"v":1.81},{"n":"level","t":120,"v":1.79}]
got level = 1.82
got level = 1.81
got level = 1.79
stream finished: true

push! adds bytes, and next_record! returns a record once all of it has arrived, or nothing to say "wait for more". Each record is checked as it comes out, so a bad record is reported where it is, not at the end of the stream.

What each format offers

JSONCBORXMLEXI
StreamEncoder (write record by record)yesyesyesyes
RecordReader (read record by record, whole input)yesyesyesyes
StreamDecoder (read as bytes arrive)yesyesnono

The JSON, CBOR and XML StreamEncoders write to any IO; the CBOR one writes an array with no length up front, as SenSML in CBOR should. The EXI StreamEncoder returns its bytes from finish!.

RecordReader is for a whole message that you don't want to turn into a Pack first, for example to look at each record and keep only some.
