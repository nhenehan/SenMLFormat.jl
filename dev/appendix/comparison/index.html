SenMLFormat and rsenml compared

SenMLFormat is the Julia port of rsenml 0.9, and this compares only those two. Speed is in performance.md, which bench/run.sh writes.

Same results

SenMLFormat gives the same answers as rsenml, and the tests check it against rsenml's own output (test/fixtures/export, written by rsenml's scripts/export-fixtures.sh):

  • the same verdict (accepted, or the same error kind) on all 66 of rsenml's conformance vectors;
  • the same bytes in all eight media types and both EXI alignments for every test case and every accepted vector, and the same sizes on the benchmark data;
  • the same EXI bytes as EXIficient 1.0.7 on all 32 streams;
  • the same 25 conformance rows, with the same numbers (conformance.md);
  • the same 10 readings of unclear points of RFC 8428 (Where the RFC is unclear).

OperationSenMLFormat / rsenml
decode (all formats)about 2× to 4× slower
encode (all formats)about 1.7× to 2.5× slower
