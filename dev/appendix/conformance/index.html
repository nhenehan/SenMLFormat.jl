Beyond the RFC's examples

  • Same verdicts as rsenml. All 66 of rsenml's conformance vectors (JSON, CBOR, SenSML CBOR; exported by rsenml's scripts/export-fixtures.sh) get rsenml's verdict, and the accepted ones the expected records (shared_vectors.jl).
  • Same bytes as rsenml. For every accepted vector and all 16 test cases, JSON, CBOR, SenSML CBOR, XML and both EXI alignments equal rsenml's bytes (shared_vectors.jl); every case in all eight media types through SenMLFormat.encode, SenMLFormat.encode_unchecked and SenMLFormat.decode (facade.jl).
  • Same bytes as EXIficient. All 32 EXIficient 1.0.7 streams (16 cases, two alignments), byte for byte (exi.jl).
  • Every case round-trips through every format, and JSON -> CBOR -> XML -> EXI -> JSON gives the original JSON (cbor.jl / cross format).
  • Only SenMLError escapes any decoder, on every truncation and on 64 random changes per input (SENML_MUTATIONS=2000 for long runs) of every case in every format, fed to every decoder and both stream decoders; nor on deep nesting, oversized CBOR lengths or an XML entity bomb (robustness.jl, json.jl, cbor.jl, xml.jl / hostile input, entity expansion is refused).
