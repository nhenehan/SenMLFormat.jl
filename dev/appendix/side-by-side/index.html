rsenml and SenMLFormat side by side

This page shows how each rsenml call looks in SenMLFormat, so you can move between Rust and Julia.

rsenml is the Rust version of SenMLFormat. SenMLFormat takes its test vectors from rsenml's fixtures/export, writes the same bytes in every format and gives the same verdicts. Its manual follows rsenml's guide chapter for chapter, with the same devices and data.

TaskSenMLFormat (Julia)rsenml (Rust)
Build a recordRecord(n = "room", v = 21.5)Record::new().with_name("room").with_value(21.5)
Build a packPack([r1, r2])[r1, r2].into_iter().collect::<Pack>()
Write JSONSenMLFormat.Json.encode(pack)rsenml::json::encode(&pack)?
Read CBORSenMLFormat.Cbor.decode(bytes)rsenml::cbor::decode(&bytes)?
Byte-aligned EXISenMLFormat.Exi.encode(pack; alignment = :byte_aligned)exi::encode_with(&pack, &EncodeOptions::new().with_alignment(Alignment::ByteAligned))
By media typeSenMLFormat.encode(SENML_CBOR, pack)rsenml::encode(MediaType::SenmlCbor, &pack)
Checkvalidate(pack)pack.validate()
Resolveresolve(pack; now)pack.resolve(Some(now))
ErrorsSenMLError, with kind (:MissingValue, ...)Result with rsenml::Error (Error::MissingValue, ...)
Record numbers in errorsfrom 1from 0

Only in rsenml: no_std and fixed buffers (encode_into).
