SenMLFormat.jl

SenMLFormat reads and writes sensor readings in Julia. This manual shows you how, one short example at a time.

The format is SenML (Sensor Measurement Lists, RFC 8428). SenML is a small, standard way for a device to report what it measured: a list of records, each with a name, a value, and maybe a unit and a time. A thermostat, a water meter and a web app can all agree on it without sharing any code.

The same list can be sent in four formats. SenMLFormat reads and writes all of them from one data model:

flowchart LR pack[Pack of records] --> json[JSON text] pack --> cbor[CBOR binary] pack --> xml[XML text] pack --> exi[EXI binary] json --> back[The same pack] cbor --> back xml --> back exi --> back

SenMLFormat is the Julia version of rsenml. It writes the same bytes in every format and gives the same verdicts on the same test data.

Installation

SenMLFormat needs Julia 1.10 or newer. In the Pkg REPL (press ]):

pkg> add SenMLFormat

or with using Pkg; Pkg.add("SenMLFormat"). It brings in EXIFormat for EXI.

Quick start

using SenMLFormat

pack = Pack([
    Record(bn = "urn:dev:mac:0024befffe804ff1:", bt = 1.7e9, n = "supply-air", u = "Cel", v = 12.8),
    Record(n = "return-air", u = "Cel", v = 24.1),
    Record(n = "compressor", vb = true),
])
for media in (SENML_JSON, SENML_CBOR, SENML_XML, SENML_EXI)
    bytes = SenMLFormat.encode(media, pack)
    @assert SenMLFormat.decode(media, bytes) == pack
    println(content_type(media), ": ", length(bytes), " bytes")
end
application/senml+json: 159 bytes
application/senml+cbor: 110 bytes
application/senml+xml: 218 bytes
application/senml-exi: 87 bytes
