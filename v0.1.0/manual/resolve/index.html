Base fields and resolving

In this chapter you'll see how base fields and relative times work, and how to turn records into full names and absolute times.

A home water meter reports its total use (a sum, in litres) every 10 minutes. The first record sets the base name, base time, base unit and a base sum. The times are relative to the base time:

# The meter sends its total (a sum, in litres) every 10 minutes. The times are
# relative to the base time: -1200 s, -600 s and 0 s.
pack = Pack([
    Record(bn = "urn:dev:mac:0024befffe804ff2:water:", bt = 1_700_000_000, bu = "l",
           bs = 48_000, n = "total", t = -1200, s = 12.5),
    Record(n = "total", t = -600, s = 19.0),
    Record(n = "total", s = 31.5),
])

# Resolving gives every record its full name, unit and time, and adds the base
# sum. "now" is only needed for times below 2^28, which this pack does not use.
for r in resolve(pack)
    println(r.name, " t=", round(Int, r.time), " u=", repr(r.unit), " sum=", r.sum)
end
urn:dev:mac:0024befffe804ff2:water:total t=1699998800 u="l" sum=48012.5
urn:dev:mac:0024befffe804ff2:water:total t=1699999400 u="l" sum=48019.0
urn:dev:mac:0024befffe804ff2:water:total t=1700000000 u="l" sum=48031.5

Resolving follows RFC 8428 section 4.6:

  • Name: base name + name.
  • Unit: the record's unit, else the base unit.
  • Time: base time + time. A result below 2^28 is relative to "now", so it needs the now you pass in (seconds since 1970). Resolving a relative time without now throws a SenMLError of kind :RelativeTime.
  • Value: base value + value, for numbers only.
  • Sum: base sum + sum.
  • The resolved records come out in time order.

A record can hold base fields and nothing else. It sets context for the records after it and resolves to nothing.

Record by record

resolve works on a whole pack. For a stream, use a Resolver: give it each record as it arrives with resolve!, and change "now" with set_now! when you need to.

Picking records out

A RecordSelector reads the rec= fragment identifiers of section 9, such as rec=3-5, and selected tells you which positions they pick. A record's meaning depends on the base fields before it, so resolve the whole pack first, then pick.
