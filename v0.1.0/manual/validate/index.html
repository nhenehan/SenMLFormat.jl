Checking packs

In this chapter you'll see what the RFC's rules refuse, and how to ask for more.

An HVAC unit reports its supply air temperature, its compressor, and its fan:

# `validate` returns nothing when the pack is good and throws a SenMLError when
# it breaks a rule. This prints which.
function check(what, pack; options...)
    try
        validate(pack; options...)
        println(what, ": ok")
    catch e
        e isa SenMLError || rethrow()
        println(what, ": ", e.kind, " (record ", e.record, ")")
    end
end

base = "urn:dev:mac:0024befffe804ff3:"
check("good pack", Pack([
    Record(bn = base, n = "supply-air", u = "Cel", v = 12.8),
    Record(n = "compressor", vb = true),
]))

# A record needs a value (or a sum).
check("no value", Pack([Record(bn = base, n = "fan")]))

# Labels ending in "_" must be understood, so an unknown one is refused.
check("unknown _ label", Pack([Record(bn = base, n = "fan", v = 0.65,
                                      extensions = ["mode_" => "eco"])]))

# "RPM" is not in the SenML units registry. RFC 8428 allows it, unless you ask
# for registered units only.
rpm = Pack([Record(bn = base, n = "fan-speed", u = "RPM", v = 900)])
check("RPM", rpm)
check("RPM, registered units only", rpm; registered_units = true)
good pack: ok
no value: MissingValue (record 1)
unknown _ label: MustUnderstand (record 1)
RPM: ok
RPM, registered units only: UnregisteredUnit (record 1)

decode runs the same checks while it reads, and encode runs them before it writes, so you only call validate yourself for packs you build or change. Records are counted from 1 in errors.

The rules

These come from RFC 8428 section 4:

  • A pack has at least one record.
  • A record has a value or a sum, unless it holds only base fields.
  • Each record has at most one value (v, vs, vb or vd), and each label at most once.
  • A record needs a name or a base name, and the full name must be a valid name.
  • Numbers must be finite (no NaN or infinity).
  • The version (bver) must be a positive integer, the same in every record, and not newer than 10.
  • A label that ends in _ and that SenMLFormat does not know is refused.

Units

RFC 8428 does not require registered units, so "RPM" passes by default. registered_units = true only allows the units of the SenML Units registry (Table 6 of section 12.1). lookup_unit tells you what a unit means.

The registry in SenMLFormat is RFC 8428's Table 6. The units added later by RFC 8798 are not in it yet.

Checking a stream

For records that arrive one at a time, a Validator checks each record with check!, and finish checks the end of the pack.
