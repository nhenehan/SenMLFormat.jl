When things go wrong

In this chapter you'll see what the errors look like.

Everything that can go wrong throws one exception type, SenMLError, in every format:

inputs = [
    "cut off" => """[{"n":"urn:dev:mac:0024befffe804ff1:room","v":21""",
    "two values" => """[{"n":"urn:dev:mac:0024befffe804ff1:room","v":21,"vb":true}]""",
    "bad name" => """[{"n":"room temp","v":21}]""",
    "newer version" => """[{"bver":11,"n":"urn:dev:mac:0024befffe804ff1:room","v":21}]""",
]
for (what, input) in inputs
    try
        pack = SenMLFormat.Json.decode(input)
        println(what, ": ok, ", length(pack), " records")
    catch e
        e isa SenMLError || rethrow()
        println(what, ": ", sprint(showerror, e))
        println("    kind = ", e.kind)
    end
end
cut off: SenMLError: JSON input ends inside the pack
    kind = Incomplete
two values: SenMLError: record 1: more than one of v, vs, vb, vd
    kind = MultipleValues
bad name: SenMLError: record 1: name must be [A-Za-z0-9][A-Za-z0-9:./_-]* (RFC 8428 4.5.1)
    kind = InvalidName
newer version: SenMLError: record 1: SenML version 11 is newer than 10 and must not be used
    kind = UnsupportedVersion

The message is for people; check kind in code. Each kind is named after rsenml's matching Error variant, so the two libraries can be checked against each other. Errors about one record say which one in record, counted from 1.

kindMeaning
:SyntaxThe bytes are not valid JSON, CBOR, XML or EXI. offset gives the byte.
:IncompleteThe input ended too early. For a stream: wait for more bytes.
:WrongType, :DuplicateLabel, :MultipleValuesA record's fields are wrong.
:MustUnderstandA label ending in _ that SenMLFormat doesn't know.
:InvalidLabelAn extension uses a name the format keeps for a registered label.
:InvalidBase64, :NonFiniteA data value or a number that SenML can't carry.
:EmptyPack, :MissingValue, :MissingName, :InvalidNameThe pack breaks a rule of section 4.
:InvalidVersion, :UnsupportedVersion, :InconsistentVersionbver problems.
:UnregisteredUnitOnly with registered_units = true.
:RelativeTimeResolving found a relative time, and no now was given.
:StructureThe XML or EXI root or record element is missing or wrong.
:SchemaIdThe EXI stream doesn't name the RFC 8428 schema ("a").
:UnrepresentableThe pack can't be written in this format.
:ExiAn error from the EXI codec that has no SenML meaning.
