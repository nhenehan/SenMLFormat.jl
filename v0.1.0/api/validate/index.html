Validation

SenMLFormat.validate — Function
validate(pack; registered_units = false)

Checks the rules of RFC 8428 section 4 (see Validator). Throws a SenMLError; returns nothing.

source
SenMLFormat.Validator — Type
Validator(; registered_units = false)

Checks the records of a pack one at a time, so a SenSML stream can be checked as its records arrive: check! each record, then finish.

With registered_units, units (u, bu) must be in the SenML Units registry (Table 6, section 12.1). RFC 8428 does not require it, so it is off by default.

source
