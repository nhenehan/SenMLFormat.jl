Media types

SenMLFormat.MediaType — Type
MediaType

The eight SenML and SenSML media types: SENML_JSON, SENSML_JSON, SENML_CBOR, SENSML_CBOR, SENML_XML, SENSML_XML, SENML_EXI, SENSML_EXI. For each format, SenML comes before SenSML.

media_type(format::Symbol, streaming::Bool) -> MediaType
media_type(content_type::AbstractString) -> Union{MediaType,Nothing}
media_type(coap_content_format::Integer) -> Union{MediaType,Nothing}

The media type of a format (:json, :cbor, :xml, :exi), of a content type (case and parameters such as ; charset=... are ignored), or of a CoAP Content-Format ID.
