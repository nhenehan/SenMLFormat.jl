Resolving

SenMLFormat.resolve — Function
resolve(pack; now = nothing) -> Vector{ResolvedRecord}

Validates the pack, resolves every record and sorts them by time, as section 4.6 asks. The sort is stable: records with equal times keep their order. now resolves relative times; without it they are an error.

source
SenMLFormat.ResolvedRecord — Type
ResolvedRecord

A record with every base value applied and an absolute time. Fields: name (base name + name), unit (or the base unit in force), value (numbers with the base value added), sum (base sum + sum, when either is present), time (absolute, seconds since the Unix epoch), update_time, version (the pack's version when it is not 10, as section 4.6 asks), extensions (regular ones only).

source
SenMLFormat.Resolver — Type
Resolver(; now = nothing)

Applies base values one record at a time (resolve!). It works the same for packs and for SenSML streams. now resolves relative times: the time the pack (or, in a stream, the record) was sent, in seconds since the Unix epoch.

source
SenMLFormat.resolve! — Function
resolve!(res::Resolver, record) -> Union{ResolvedRecord,Nothing}

Applies the record's base fields, then resolves it. Returns nothing for a record with only base fields. The record should have passed validation.

The steps follow section 4.6: name = bn + n; unit = u, or else bu; value = bv + v; time = bt + t, plus "now" when the total is relative.

source
SenMLFormat.set_now! — Function
set_now!(r::Resolver, now)

Changes "now" for the records that follow. In a SenSML stream, "now" is set for each record (section 4.8).

source
SenMLFormat.to_record — Function
to_record(r::ResolvedRecord) -> Record

The resolved record as a plain record (bver carries the version when it is not 10), so a resolved pack can be written in any format.

source
SenMLFormat.is_relative_time — Function

True when t is a relative time (below 2^28).

source
SenMLFormat.ABSOLUTE_TIME_THRESHOLD — Constant

2^28 (268,435,456). Times at or above this are absolute (seconds since the Unix epoch). Times below it are relative to "now" (section 4.5.3).

Fragment identifiers

SenMLFormat.RecordSelector — Type
RecordSelector

A parsed rec= fragment identifier (section 9.1 has examples). ranges holds (first, last) pairs, 1-based; last is typemax(Int) for n-*.

Make one with parse(RecordSelector, "rec=3-5,10,19-*") (a leading # is allowed) or tryparse.
